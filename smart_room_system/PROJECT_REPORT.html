เอกสารรายงานฉบับสมบูรณ์

รายงานโครงงานการพัฒนาเว็บแอปพลิเคชันและ RESTful API

ระบบบริหารจัดการและจองห้องเรียน/ห้องประชุมอัจฉริยะ (Smart Room Reservation System)

วิชาการพัฒนาเว็บแอปพลิเคชันและบริการบนเว็บ (Web Application & API Development)

ประเภทโครงงาน: โครงงานกลุ่ม (2 คน)
สถาปัตยกรรม: Django 6.0, Django REST Framework, SimpleJWT
ระบบยืนยันตัวตน: 6-Digit OTP PIN (Google App Password / Gmail SMTP)
การทดสอบ: Django Test Suite (7/7 Pass 100%)

บทที่ 1: บทนำและวัตถุประสงค์

ในองค์กรการศึกษาและสำนักงานยุคใหม่ การจัดสรรทรัพยากรห้องเรียน ห้องปฏิบัติการ และห้องประชุม มีความสำคัญอย่างยิ่งต่อประสิทธิภาพการดำเนินงาน ปัญหาที่พบบ่อยในระบบดั้งเดิมคือการจองเวลาซ้ำซ้อน (Double Booking) และการขาดระบบยืนยันตัวตนที่ปลอดภัย

โครงงานนี้พัฒนาขึ้นเพื่อให้บริการ RESTful API ที่มีความปลอดภัยด้วยมาตรฐาน Token Authentication (SimpleJWT) ควบคู่กับระบบส่งรหัสยืนยัน OTP PIN 6 หลักทางอีเมลผ่าน Google App Password และมีหน้าจอ Institutional Gateway ตามมาตรฐานทางการของหน่วยงานภาครัฐและมหาวิทยาลัย

บทที่ 2: บทบาทผู้ใช้งานในระบบ (Role-Based Access Control)

บทบาท (Role) สิทธิ์การเข้าถึงและการทำงาน
User (ผู้ใช้ทั่วไป) ลงทะเบียน, ยืนยัน OTP PIN 6 หลัก, จองห้อง, ตรวจสอบตารางเวลาว่าง, ดูประวัติและยกเลิกคำขอของตนเอง
Staff (เจ้าหน้าที่สถานที่) ตรวจสอบคำขอจองทั้งหมด, พิจารณาอนุมัติ (Approve) หรือปฏิเสธ (Reject พร้อมระบุเหตุผล), จัดการข้อมูลห้อง
Administrator (ผู้ดูแลระบบ) จัดการผู้ใช้ทั้งหมด, กำหนดสิทธิ์บทบาท, จัดการห้องเรียน/ห้องประชุม, เข้าถึงแดชบอร์ดสรุปสถิติภาพรวม

บทที่ 3: ระบบส่งรหัสยืนยัน OTP PIN 6 หลัก (Google App Password)

เพื่อป้องกันการสมัครด้วยอีเมลปลอม ระบบจะสร้างรหัสตัวเลข 6 หลัก (อายุ 10 นาที) และจัดส่งไปยังอีเมลของผู้ใช้ผ่าน Gmail SMTP โดยใช้รหัสผ่าน Google App Password ทางการ เมื่อผู้ใช้ยืนยันรหัสถูกต้อง บัญชีจะได้รับการเปิดใช้งาน (is_verified = True) และได้รับ JWT Token เข้าสู่ระบบทันที

บทที่ 4: สรุปรายการ RESTful API (21 Endpoints)

Method URL Path สิทธิ์ คำอธิบาย
POST/api/auth/register/Publicลงทะเบียนผู้ใช้และส่งรหัส OTP 6 หลัก
POST/api/auth/verify-otp/Publicยืนยัน PIN 6 หลักเพื่อเปิดใช้งานบัญชีและรับ JWT
POST/api/auth/resend-otp/Publicขอส่งรหัส PIN 6 หลักใหม่อีกครั้ง
POST/api/auth/login/Publicเข้าสู่ระบบเพื่อรับ JWT Access / Refresh Token
GET/api/auth/profile/Bearerดูข้อมูลโปรไฟล์และบทบาทของตนเอง
GET/api/rooms/Publicดูรายการห้องทั้งหมด พร้อมตัวกรองประเภท
POST/api/rooms/Staff/Adminสร้างห้องใหม่
GET/api/rooms/{id}/availability/Publicตรวจสอบตารางเวลาว่างของห้องในแต่ละวัน
GET/api/bookings/Bearerดูรายการจองห้อง (User ดูของตน, Admin ดูทั้งหมด)
POST/api/bookings/Bearerสร้างคำขอจอง (ตรวจสอบเวลาชนอัตโนมัติ)
POST/api/bookings/{id}/approve/Staff/Adminอนุมัติคำขอจอง
POST/api/bookings/{id}/reject/Staff/Adminปฏิเสธคำขอจอง พร้อมระบุเหตุผล
POST/api/bookings/{id}/cancel/Owner/Adminยกเลิกรายการจอง
GET/api/dashboard/stats/Bearerสรุปสถิติภาพรวมและการใช้งานห้อง
