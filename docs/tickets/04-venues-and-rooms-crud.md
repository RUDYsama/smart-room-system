# 04: Advanced Venues & Rooms Management Console

**What to build:**
Comprehensive venue administration console enabling creation, editing, pricing structure configuration (daily vs hourly), multi-photo gallery management, and status control (available, maintenance, closed).

**Blocked by:** 01-core-navigation-and-layout.md

**Status:** ready-for-agent

- [ ] Provide backend REST APIs: `GET/POST /api/admin/rooms/`, `PUT/DELETE /api/admin/rooms/<id>/`, and gallery endpoints.
- [ ] Admin can view room directory with thumbnail, room code, name, category, capacity, and pricing.
- [ ] Admin can configure daily vs hourly stay rates, description, amenities, and upload cover and gallery photos.
- [ ] Admin can toggle room availability and maintenance mode instantly.
