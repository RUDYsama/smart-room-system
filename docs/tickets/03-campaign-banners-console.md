# 03: Promotional Campaign Banners Management Console

**What to build:**
Interactive visual banner manager allowing administrators to upload campaign artwork, configure badge titles, link database coupons (primary and secondary), define campaign terms, and live-preview the Shopee-style modal.

**Blocked by:** 02-coupon-management-crud.md

**Status:** ready-for-agent

- [ ] Provide backend REST APIs: `GET/POST /api/admin/banners/`, `PUT/DELETE /api/admin/banners/<id>/`, and reordering.
- [ ] Admin can view wide and compact banners in visual galleries with live image previews.
- [ ] Admin can add or edit campaign banners, select coupon relations via dropdown, and edit terms.
- [ ] Admin can trigger a live pop-up preview directly in the console.
